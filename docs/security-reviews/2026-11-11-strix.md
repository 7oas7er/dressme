## Findings (index only)

Do not treat this table as new disclosure — detail lives in the dumps above. Independent
triage (same morning) closed the HIGH black-box claim and the Trufflehog “token” hit as
false positives; remaining items are hygiene already shipped or deferred defense-in-depth.

| ID | Source | Claim (short) | Verdict |
|----|--------|---------------|---------|
| **BB-1** | black-box | `alg=none` JWT “bypass” on `GET /api/config` | **False positive** — endpoint is intentionally public SPA Cognito bootstrap; other `/api/*` reject bad tokens via `aws-jwt-verify`. Pool/client IDs are public by Cognito SPA design. Do **not** add JWT auth to `/api/config`. |
| **WB-1** | white-box | Cloudflare API token in `.git` internal refs | **False positive** — Trufflehog unverified; string is a git tip SHA in `packed-refs` / `info/refs`, not a Cloudflare token. |
| **WB-2a** | white-box / Trivy | S3 media versioning disabled | **Stale** — media bucket versioning already Enabled in Terraform. |
| **WB-2b** | white-box / Trivy | S3 logging disabled | **Remediated in-repo** — see below. |
| **WB-2c/d/e** | white-box / Trivy | CMK, CloudFront AWS WAF, DDB/CW/X-Ray hardening | **Defer / accept** for solo v1 (cost vs €10 ceiling; L7 edge is Cloudflare shared-edge, not AWS WAFv2 on the distribution). |
| **WB-3** | white-box | Bedrock prompt-field surface | **Accept** for single-user v1; optional sanitize later. |
| **WB-4** | white-box | Dependabot missing `cooldown` | **Remediated in-repo** — see below. |

White-box executive claim (no critical/high application-layer vulns) holds with BB-1 and
WB-1 as false positives.
